# Project Overview

Cabo Bay Transportation is a production-ready web application built for a transportation company operating in Los Cabos, Baja California Sur.

The platform allows customers to reserve private airport transportation online while providing administrators with an internal dashboard to manage bookings, destinations, pricing, and multimedia content.

The project was designed with scalability and maintainability in mind, separating the public website from the administration system.
